# Marina Birthday Website ❤️

## How to use
1. Open `index.html` in Chrome/Edge/Firefox.
2. The website works offline because the photos are included in `assets/`.
3. To put it online, upload the whole folder to any static web host.

## Files
- `index.html` — complete website
- `assets/` — optimized copies of the uploaded photos

## Birthday date
The countdown is set for 27 August 2026 (Malaysia local time).

## Personalization
The main message is already personalized for Marina and signed from Haziq.
You can edit the text directly in `index.html` if you want to change any wording.
